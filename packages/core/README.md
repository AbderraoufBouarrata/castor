# @castor/core

Shared code for the Castor apps.

## Contents

| File | Export | What |
|---|---|---|
| `job-state.js` | `STATES` | List of job states: `waiting`, `queued`, `rejected`, `building`, `running`, `done`, `failed` |

## Usage

```js
import { STATES } from '@castor/core';
```

No build step and no dependencies. Plain ES modules, Node 22 or newer.

## Commands

None.
